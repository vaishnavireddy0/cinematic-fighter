# CINEMATIC FIGHTER

A browser-based 3D cinematic fighting game built with Three.js.

Experience 3D combat with animated fighters, opponent AI, combat reactions, critical hits, health systems, and cinematic knockout sequences.

## Features

- 3D character rendering with Three.js
- FBX character models and animations
- Player movement and combat controls
- AI-controlled opponent
- Punch and kick attacks
- Health bars and combat status
- Hit reactions and knockback
- Critical hit system
- Cinematic knockout camera
- Browser-based gameplay

## Controls

| Key | Action |
|---|---|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| J | Punch |
| K | Kick |

## Tech Stack

- JavaScript
- Three.js
- HTML5
- CSS3
- Vite
- FBX animation models

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vaishnavireddy0/cinematic-fighter.git
```

### 2. Enter the project directory

```bash
cd cinematic-fighter
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

```bash
npm run build
```
